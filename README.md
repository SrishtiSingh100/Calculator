
# 🌸 Aesthetic Calculator

A simple and functional calculator built using HTML, CSS, and JavaScript.

## ✨ Features
- Basic arithmetic operations (+, -, *, /, %)
- Decimal number support
- Clear and delete functionality
- Keyboard support
- Responsive design

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
